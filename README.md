# AFYALINK – Hospital ERP System

## Overview
AFYALINK is a comprehensive Hospital ERP System designed to streamline and digitize hospital operations across multiple departments. It integrates clinical, administrative, and financial workflows into a unified platform.

---

## Core Modules

The system covers the following functional areas:

1. Outpatient Management
2. Doctors Management System
3. Pharmacy
4. Pathology
5. Inpatient Management
6. Payroll
7. Inventory Management
8. Radiology
9. Blood Bank Management
10. Record Management
11. Billing Management
12. Front Office
13. Download Center
14. Calendar & To-Do List
15. Ambulance Management
16. Communication System

---

## Technology Stack

### ERP Backend
- Platform: Microsoft Dynamics 365 Business Central  
- Language: Application Language (AL)  
- Purpose: Core hospital operations, data management, and business logic  

### Patient Portal
- Framework: Laravel 13  
- Integration: Connected to ERP via NTLM Authentication  
- Purpose: Enables patients to interact with the system (e.g., appointments, records)

### Upcoming Feature
- Staff Portal
  - Role-based access system
  - Customized interfaces for:
    - Doctors
    - HR
    - Administrative staff
  - Deep integration with ERP data and workflows
